# AI Resume Screening System

## Overview
An NLP-based application that analyzes resume-job fit using TF-IDF and cosine similarity.

## Features
- Match score calculation
- Keyword extraction
- Missing skill detection
- PDF/TXT resume upload
- Interactive Streamlit UI

## Tech Stack
Python, Streamlit, Scikit-learn, PyPDF2

## Run Locally
pip install -r requirements.txt  
streamlit run app.py
